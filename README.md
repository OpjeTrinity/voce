## Setup

### 1. Pusher Credentials

1. Create an app at [dashboard.pusher.com](https://dashboard.pusher.com)
2. Note your `App ID`, `Key`, `Secret`, and `Cluster`
3. **Enable Client Events** in App Settings (optional — standard events used by default)

### 2. Configure Pusher Keys in HTML

Edit `public/index.html` and `public/host.html`:

```js
window.VOCE_CONFIG = {
  pusherKey:     'YOUR_PUSHER_KEY',     // ← your public app key
  pusherCluster: 'YOUR_PUSHER_CLUSTER', // ← e.g. 'ap2'
};
```

### 3. Set Environment Variables

Add to **Vercel Project Settings → Environment Variables**:

| Variable         | Value                |
|------------------|----------------------|
| `PUSHER_APP_ID`  | your app id          |
| `PUSHER_KEY`     | your public key      |
| `PUSHER_SECRET`  | your secret key      |
| `PUSHER_CLUSTER` | your cluster (e.g. `ap2`) |
| `DETONATE_SECRET`| *(optional)* a passphrase to gate the detonate endpoint |

### 4. Local Video Asset (Optional)

Place a video file at `public/assets/drop.mp4`.
If absent, the app falls back to a YouTube iframe embed.

```
public/assets/drop.mp4   ← your rickroll / mass climax video
public/assets/sfx/alarm.mp3
```

### 5. Deploy

```bash
# Install Vercel CLI
npm i -g vercel

# Install dependencies
npm install

# Local dev
npm start        # runs: vercel dev

# Deploy to production
vercel --prod
```

## Technical Notes

### Mobile Autoplay Pre-Warming
iOS Safari and Android Chrome block `video.play()` calls unless triggered by a user gesture. VOCE handles this by calling `video.play()` → immediate `video.pause()` inside the "CONNECT" button click handler. This marks the element as "user-activated", allowing later programmatic play from the WebSocket event.

### Acoustic Energy Model
```
currentEnergy       = totalIncomingEnergy
totalIncomingEnergy = totalIncomingEnergy × 0.65   (decay per tick)

Δprogress = ((currentEnergy - 35) / 100)^2.2 × 2.8
progress  = min(progress + Δprogress, 100)
```

### Bottleneck Gate
Progress locks at 75% until `currentEnergy ≥ 120` (whole room screaming).
